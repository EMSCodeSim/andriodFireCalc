# FireOps Calc — Legacy Android

Dedicated source for the established FireOps Calc Google Play app. This repository is intentionally maintained as a separate product from the newer Flutter/Dreamflow FireOps Calc rebuild and from the public FireOps Calc website.

## Current Android release baseline

- Application ID: `com.fireopscalc.app`
- Version code: `94`
- Version name: `9.1.4`
- Compile SDK: `36`
- Target SDK: `36` (Android 16)
- Minimum SDK: `24`
- Capacitor: `8.5.0`
- Cordova purchase plugin: `13.13.1`
- Google Play Billing client generated by the purchase plugin: `8.3.0`

The original user-provided version 84 / 9.0.4 APK and AAB are the compatibility reference for the existing Play Store application identity and legacy Android experience. A later Android-capable source version was used to recover the maintainable project before the API 36 migration.

## Source-of-truth policy

`EMSCodeSim/andriodFireCalc` is now the source of truth for the legacy Android app.

The build workflow MUST NOT:

- clone or import UI files from `EMSCodeSim/pump`
- clone or import the newer Flutter/Dreamflow FireOps Calc project
- overwrite `www/` from a website deployment
- change the Google Play application ID

The committed `www/` directory is the packaged legacy calculator source. Website and Flutter development must not automatically flow into this app.

## Repository layout

- `www/` — legacy FireOps Calc web bundle packaged into the Android app
- `android/` — native Capacitor Android project
- `scripts/` — API/version and signing verification tools
- `.github/workflows/bootstrap-from-pump.yml` — isolated legacy Android CI build (historical filename; it no longer imports from `pump`)
- `codemagic.yaml` — signed release AAB build configuration

## Setup

Requirements include Node.js 22+, JDK 21, and Android SDK/API 36.

```bash
npm install
npm run android:sync
npm run android:verify
npm run android:open
```

The existing `android/` project is committed, so normally use `android:sync`. Use `android:add` only if intentionally regenerating the Android platform from scratch.

## Play Store safety

Do not change `com.fireopscalc.app`. A Google Play update must keep the existing application ID and must be signed with an upload key accepted by the current FireOps Calc listing.

The upload certificate from the archived production AAB has been recorded in `scripts/verify-upload-key.sh`. After producing a signed AAB, verify it before upload:

```bash
bash scripts/verify-upload-key.sh path/to/FireOpsCalc.aab
```

A `PASS` means the bundle certificate matches the original FireOps Calc upload certificate recovered from the version 84 AAB.

See `BUILD_ANDROID_16.md` for build/signing details.
